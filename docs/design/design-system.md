# Design system

**Status:** Not started (Phase 2). Branding assets are pending (see the [clinic checklist](../product/clinic-information-checklist.md) item 11).

Phase 2 will define: brand tokens (primitive → semantic → component), typography scale, spacing
scale, colour system with AA contrast checks, elevation and border rules, icon rules (Lucide
only, no emoji), button hierarchy, form/table/modal/drawer/toast patterns, breakpoints and motion
(with reduced-motion support), along with a `/app/design-system` showcase page.

Two related but distinct expressions:
- **Public website:** premium, calm and trustworthy. Generous whitespace, real photography (when
  supplied), strong WhatsApp CTA, minimal motion.
- **Staff dashboard:** healthcare SaaS. Dense but readable tables, clear status colour plus text plus
  icon (never colour alone), consistent page headers, keyboard-first.

If brand assets are not supplied by Phase 2, a **provisional** palette is used. It is marked
`PROVISIONAL` in the token file and is designed to be replaced by editing primitive tokens only.
